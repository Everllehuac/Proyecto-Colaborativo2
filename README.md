### Pregunta final:
**¿Cómo facilita GitHub el trabajo colaborativo en un proyecto de desarrollo de software?**

GitHub facilita la colaboración al permitir que múltiples desarrolladores trabajen en paralelo mediante ramas individuales sin sobreescribir el trabajo de los demás. A través de los *Pull Requests*, el equipo puede revisar y comentar los cambios antes de integrarlos al proyecto principal, mientras que el historial de *Commits* y los *Issues* garantizan trazabilidad total y una asignación ordenada de tareas.# Proyecto-Colaborativo2
